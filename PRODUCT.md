# Product

<!-- impeccable:product-schema 1 -->

## Platform

Terminal application on macOS and Linux, including SSH and tmux.

## Stack

User specified Python 3.11+, Textual, Rich, Typer, Pydantic, SQLite, asyncio, HTTPX, Git and Gemini CLI.

## Users

Individual developers and teams coordinating assigned sprint tickets locally, with separate profiles.

## Product Purpose

Select assigned Jira work, inspect deterministic dependency plans, approve isolated coding agents, verify their changes, and review implementations before optional remote publication.

## Capabilities and Constraints

Human approval governs selection, planning, worker launch, acceptance, pushes and draft requests. Jira is strictly read-only. Demo mode uses synthetic data and real Git worktrees. Company access and publication require explicit approval. No license has been selected.

## Product Principles

Human control, predictable execution, durable evidence, local profile isolation, and safe failure take precedence over autonomous throughput.

## Evidence on Hand

The user supplied a complete implementation brief. There is no incumbent application, branding, enterprise data, or validated live integration. Real enterprise validation will happen on approved work systems.

## Open Decisions

Software license and publication authorization remain with the user. Terminal layout details are implementation choices under the user's instruction to proceed through implementation without pausing for another plan.
